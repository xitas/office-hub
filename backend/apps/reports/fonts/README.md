Fonts for PDF exports (embedded, subset, in every PDF):

- Noto Sans (Regular, Bold): Latin text and numbers.
- Noto Nastaliq Urdu (Regular, Bold): Urdu, shaped with HarfBuzz (uharfbuzz) so letters join and stack as in print.

Both are from the Noto project (https://github.com/notofonts) under the SIL Open Font License 1.1 (OFL.txt).
